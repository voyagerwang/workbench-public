# 个人工作台

本地优先的个人工作台，包含今日规划、清单、项目、笔记、日程、提醒、知识管理和 AI 助手。

## 运行

需要 Node.js 22 和 npm。

```sh
npm ci
npm start
```

打开 http://localhost:8787 。开发模式使用 `npm run dev`，页面地址为 http://localhost:5173 。

## 数据与隐私

- 首次启动创建空数据库；不附带作者的个人资料、账号或模型密钥。
- 数据默认保存在本机 `data/`，升级时保留该目录；请妥善保管，其中可能包含账号凭据。
- AI 请求会将相关内容发送到用户配置的模型服务；外部连接和云同步默认关闭。
- 默认仅本机可访问；非本机监听必须设置访问令牌，并显式配置允许的网页来源。
- 数据导出暂不等于完整可恢复备份。提醒需要服务持续运行，关机或睡眠会影响送达。
- 外部平台、CLI 与文档转换能力需要相应运行环境。
